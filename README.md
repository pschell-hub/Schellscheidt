# schellscheidt.net

Website of Schellscheidt d.o.o. (Patrick Schellscheidt), the company page that leads to Journey to Change.

## What is in this repository

- `index.html` – home page ("Coaching & Consulting")
- `legal.html` – legal notice
- `styles.css` – the shared design
- `images/` – photo and logo used by the pages
- `images/logos/` – original logos and favicons from the older site archive

The live site still runs on Google Sites until the new version is published.
